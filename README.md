# Консольная БД

Учебное консольное приложение для работы с таблицами и записями.

## Требования

- Python 3.13 или выше
- uv

## Установка

```bash
git clone https://github.com/ArinaVinar/project2_Vinar_M26-555.git
cd REPOSITORY
uv sync
```

## Запуск

```bash
uv run database
```

Или:

```bash
make run
```

## Проверка кода

```bash
make lint
```

## Сборка

```bash
make build
```
